# ЛР3 — Матрицы в 3D-графике

**Дедлайн защиты:** день 5 · **Методичка:** `tasks/PLA_LAB3_2025.pdf`
**Теория:** лекция 2 (Линейная), лекция 4 (матричная экспонента)

## О чём работа

Однородные координаты и аффинные преобразования: масштаб, перенос, поворот вокруг
произвольной оси через матричную экспоненту, камера и перспектива.
**Все преобразования координат обязаны быть сделаны матрицами** — это требование методички.

## Блок A — Альберт Осипов (задания 1–3)

- Общие исходные данные: `draft.md`.
- Расчёты, пояснения, рисунки и выводы по заданиям 1–3: `draft_A.md`.

  Программа сохраняет четыре рисунка в `figures/*.png` и открывает окна графиков.
- Текущий статус: черновик заданий 1–3 заполнен, код и расчёты проверены;
  отчёт блока A — `report/report.pdf`, LaTeX-исходник — `report/report.tex`.

### Сборка PDF блока A

```bash
python3 labs/lab03/report/build_report.py
```

Скрипт читает `draft.md` и `draft_A.md`, строит рисунки с крупными подписями
по данным `code/block_a.py`, генерирует `report/report.tex` и собирает PDF.
Нужен установленный XeLaTeX или Tectonic. Для движка вне `PATH`:

```bash
python3 labs/lab03/report/build_report.py --engine /путь/к/tectonic
```

Шрифты — как в общем шаблоне: Liberation Serif, Liberation Sans,
DejaVu Sans Mono и DejaVu Math TeX Gyre. Если шрифты доступны файлами,
но не установлены в системе, можно передать `--font-dir /путь/к/ttf`.
После правок черновика нужно повторять сборку скриптом: `report.tex` генерируется заново.
PDF содержит только задания 1–3, заключение по этому блоку и приложение с кодом.

## Грабли

- Четвёртая координата нужна, чтобы перенос стал линейным (в 3D он аффинный).
  Ответ на «почему 4 компоненты, а не 3» — обязателен в задании 1.
- Перед отрисовкой делить на 4-ю координату (`vertices[:3]/vertices[3]`) — иначе перспектива не сработает.
- Порядок умножения: последняя применённая матрица стоит слева.
- $e^{J\theta}$ считать `scipy.linalg.expm`, но в отчёте показать и формулу Родрига.
