# ЛР4 — Динамические системы

**Дедлайн защиты:** день 6 · **Методичка:** `tasks/PLA_LAB4_2025.pdf`
**Теория:** лекция 3 (Спектральная), лекция 4 (Динамическая) + вводные видео про диффуры

## О чём работа

Связь спектра матрицы $A$ с поведением систем $\dot x = Ax$ (непрерывных) и
$x(k{+}1) = Ax(k)$ (дискретных). Главная идея: собственные числа определяют
устойчивость, собственные векторы — направления инвариантных траекторий.
Для непрерывных решает знак $\mathrm{Re}\,\lambda$, для дискретных — модуль $|\lambda|$
относительно единичной окружности.

## Грабли

- П.2 задания 1 — неустойчивая с одним собственным вектором: жорданова клетка с $\lambda > 0$.
- П.3 — неустойчивая, но одна траектория стремится к нулю: седло ($\lambda_1 < 0 < \lambda_2$),
  начальное условие на устойчивом собственном векторе.
- П.6 — центр: чисто мнимые λ, $\mathrm{Re}\,\lambda = 0$.
- Задание 2, п.12 ($\lambda = 0$) — нильпотентная матрица, отсюда «сходимость за конечное число шагов».
- Матрица по заданным собственным числам и векторам: $A = V \Lambda V^{-1}$.
  Требование «не диагональная и не жорданова» = брать $V \ne I$.
