## О чём работа

Две самые «прикладные» задачи курса: спектральная кластеризация графа через
матрицу Лапласа и PageRank как поиск собственного вектора стохастической матрицы.
Обе напрямую полезны в ML и анализе данных.

## Чек-лист сдачи

Задание 1 — кластеризация:
- [ ] связный граф на 15–30 вершин с визуально заметными, но не изолированными сообществами
- [ ] вершины пронумерованы 1…n, изображение графа приведено
- [ ] матрица Лапласа $L = D - A$ и её собственные числа
- [ ] приведены собственные векторы в количестве, равном максимальному выбранному $k$
- [ ] матрица $V$ из $k$ векторов при наименьших λ; k-means по строкам $V$
- [ ] кластеризация выполнена для **5 разных значений $k$**, для каждого — раскрашенный граф
- [ ] объяснено, **почему это работает** (своими словами)
- [ ] выводы о сравнении результатов при разных $k$

Задание 2 — PageRank:
- [ ] связный ориентированный граф: 10–15 вершин, 25–50 дуг, из каждой вершины выходит хотя бы одна
- [ ] изображение графа с пронумерованными вершинами
- [ ] матрица $M$ (столбцово-стохастическая) и её собственные числа
- [ ] собственный вектор при наибольшем собственном числе
- [ ] ранжирование страниц при $d = 1$, результат представлен
- [ ] описана логика алгоритма: роль $d$, роль собственного вектора, связь с марковскими процессами
- [ ] выводы

Оформление:
- [ ] локальные выводы, заключение, код в приложении

## Контрольные вопросы

- [ ] Что такое граф, виды графов, компоненты связности
- [ ] Матрица Лапласа: как составить, зачем нужна, какие у неё собственные числа и что они показывают
- [ ] Кластеризация графа; как находить «слабые связи»
- [ ] Матрица инцидентности: как составить, как связана с лапласианом
- [ ] Матрица смежности: как составить, как используется для марковских процессов
- [ ] Вектор вероятности; марковский процесс; связь с динамическими системами; предельный вектор вероятности
- [ ] Собственные числа и векторы матрицы вероятности; что если наибольшее собственное число кратно
- [ ] Основная идея PageRank; связь с марковскими процессами; что если у вершины нет исходящих ссылок и как с этим бороться

## Грабли

- $\lambda_1 = 0$ у лапласиана всегда, соответствующий вектор — константа. Кратность нуля = число компонент связности.
- Второе наименьшее собственное число — алгебраическая связность (число Фидлера), его вектор и разделяет граф.
- $M$ строится по столбцам: $m_{ij}$ — доля ссылок **с j-й** страницы **на i-ю**. Сумма по столбцу = 1.
- Наибольшее собственное число стохастической матрицы равно 1 (теорема Перрона — Фробениуса).
- Собственный вектор из numpy может быть с отрицательным знаком — нормировать так, чтобы сумма была 1.
- Стек: `networkx` для графов, `sklearn.cluster.KMeans` для кластеризации.
