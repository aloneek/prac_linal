# ЛР6 — Singular Value Decomposition

**Дедлайн защиты:** день 8 (отчёт в срок → защита не нужна)
**Методичка:** `tasks/PLA_LAB6_2025.pdf` · **Теория:** лекция 6 (Сингулярная)

## О чём работа

SVD как универсальный инструмент понижения ранга: сжатие изображений и латентно-семантический
анализ текста. LSA — фактически предок современных эмбеддингов, так что эта лаба ближе всего
к тому, чем занимаются языковые модели.

## Грабли

- Степень сжатия: хранить надо $k(m + n + 1)$ чисел вместо $mn$. Именно это отношение и считается.
- `np.linalg.svd` возвращает $V^\top$, а не $V$ — на этом ошибаются чаще всего.
- Восстановленную матрицу обрезать в диапазон [0, 255] перед сохранением в изображение.
- `pymorphy2` на новых Python бывает ломается — если так, есть `pymorphy3` с тем же API.
- Знаки сингулярных векторов не определены; при интерпретации тем смотреть на модуль отклонения.
